Pool of Radiance, native on your machine

SSI's classic, rebuilt from Turbo Pascal source as a native Windows, macOS and Linux program. It keeps the game as it was and adds fixes, a settings screen, a bestiary, a vault, game statistics and more.

Download a release View the source

What this is

A reconstruction of SSI's version 1.3 in Turbo Pascal 6, built to run natively. The repository also rebuilds the original v1.1, v1.2 and v1.3 releases and compares them with SSI's own, so the port stays faithful to the game.

Bring your own game. The original game data is not included. The port reads the files from your own GOG or Steam copy and will usually find them for you. The game only needs to be installed; you don't have to run it first.

What's new

A few of the additions players notice most. The full list is in the detailed changes.

Settings screen

Game speed, monster pictures, portraits, music, sound and quick-combat options, saved for every game in POOLOPT.CFG.

The Bestiary (F2)

Records what your party has learned about each creature: armor class, hit dice, size, defenses and attacks. A sage in New Phlan will fill in entries for a fee.

Statistics

Kills by kind, damage dealt and taken, healing, loot, spells cast and deaths, for each character and for the whole game.

Paladins and rangers

Both can now be created, with Curse of the Azure Bonds' party rules.

More Info pages

Saving throws, game stats, kill count, thief skills and a turn undead table for clerics and paladins.

Quick save and load

F5 saves and F8 loads, plus a full-screen Load/Save menu.

The Hoarder's Respite

A vault in New Phlan for stashing what you can't carry.

Many fixes

Rules, combat AI, scripts and data fixes, including SSI quirks, with every change documented.

Get started

Native builds are published on the releases page.

PlatformArchive
Windows64-bit (x64) and 32-bit (x86) zips. The x86 build also runs on 32-bit Windows.
macOSApple Silicon.
Linuxx86_64 and i386 tarballs.
  1. Install Pool of Radiance from GOG or Steam (Forgotten Realms: The Archives, Collection Two).
  2. Download the archive for your system from Releases and unpack it anywhere.
  3. Run poolrad. The game looks for your data folder (GEO1.DAX) and remembers it. To choose another copy, run it with --choose-data-folder or --data-folder "path".
  4. Optional: run poolcfg for video, sound, introduction and folder options. No POOL.CFG is needed to play.

Keep the files that ship with a release (RAVFULL.DAX, SBSFX.DAT and DEMO.DAX) beside the program. On Windows, keep SDL3.dll beside it too. On a Mac, Option is the game's Alt key.

Each release's README, in docs/dist-readmes, has the details for your platform, including where saved games live.
